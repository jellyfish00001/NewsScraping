# 上稿單範本使用說明 (Templates Guide)

## 欄位填寫與放置內容說明

| 欄位位置 | 欄位名稱 | 填寫標準與內容放置方式 |
| :--- | :--- | :--- |
| 第 1 列 | **中文標題** | 填入客觀繁體中文標題（20~30 字），使用標準純黑字體，**無特殊底色或螢光色**。 |
| 第 2 列 | **外文標題** | 填入專業越南文標題（20~30 字），使用標準純黑字體，**無特殊底色或螢光色**。 |
| 第 3~8 列 | **固定分類欄位** | 新聞專區、專欄專題、一指通、影音專區等維持固定選項結構，不需更動。 |
| 第 9 列左 | **主圖 (左側)** | 嵌入經裁切為 **約 516*292 等比例規格** 之新聞配圖（寬度約 2.14 英吋 / 5.42 cm）。 |
| 第 9 列右 | **主圖 (圖說)** | 填寫格式為：**`主圖說明(Ảnh envato/{圖片名稱})`**（純黑文字，無底色，不加最外層大括號）。 |
| 第 10~12 列 | **插圖1/2/標籤** | 維持固定結構（插圖 2 維持 `（圖／提供）`）。 |
| 第 13 列 | **關鍵字** | 填入 4 個核心主題越南文關鍵字（以半形逗號分隔），純黑字體，無底色。 |
| 第 14 列 | **相關連結** | **必須填入原始真實 URL 網址（如 `https://tuoitre.vn/...`）**，嚴禁填入越文說明文字，且底層超連結目標必須與顯示網址完全一致。 |
| 表格下方 | **新聞內文** | 依五段式標準新聞架構排版（Times New Roman 12pt、段前 12pt、段後 12pt、行距 1.15 倍，純黑字體）。 |
