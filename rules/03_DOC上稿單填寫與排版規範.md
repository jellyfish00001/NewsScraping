# 03. DOC 上稿單填寫與排版規範手冊

> **規範定位**  
> 本手冊依據公司原始上稿單（`VN090602.docx`）制定，統一規範「新住民全球新聞網」每日新聞 Word 交付文件之填寫標準、排版樣式與產出流程。

---

## 一、上稿單表格欄位填寫規範

上稿單表格區分「固定結構」與「每日動態調整」兩大部分：

| 欄位名稱 | 屬性 | 格式規範與填寫標準 |
| :--- | :---: | :--- |
| **中文標題** | 動態 | 繁體中文，20~30 字，點出核心事件與影響。**使用標準黑色文字，不添加特殊底色或螢光色**。 |
| **外文標題** | 動態 | 越南文（Tiếng Việt tự nhiên），20~30 字。**使用標準黑色文字，不添加特殊底色或螢光色**。 |
| **新聞專區** | 固定 | 維持原範本分類矩陣與標記（如：重點新聞、新聞總覽），不需變動。 |
| **專欄專題** | 固定 | 維持原範本選項（專題報導、雙語專區、新住民看台灣...），不需變動。 |
| **一指通** | 固定 | 維持原範本選項（生活服務、健康醫療、培力就業...），不需變動。 |
| **影音專區** | 固定 | 維持原範本選項（影音新聞、語言教學...），不需變動。 |
| **主圖 (左側)** | 動態 | 嵌入經裁切為 **約 516*292 等比例規格** 之新聞配圖（寬度約 2.14 英吋 / 5.42 cm）。 |
| **主圖 (右側圖說)** | 動態 | **強制命名格式**：`{主圖說明(Ảnh envato/{圖片名稱})}`<br>• 範例：`Thẻ căn cước công dân gắn chíp điện tử cho người Việt Nam định cư ở nước ngoài(Ảnh envato/vietnam_id_card)`<br>• **文字為純黑，去除任何背景高亮色**。 |
| **插圖1 / 插圖2 / 標籤** | 固定 | 維持原範本結構（插圖2保留 `（圖／提供）`）。 |
| **關鍵字** | 動態 | 填入 4 個越南文核心主題關鍵字（以半形逗號分隔），**標準純黑文字，無底色**。 |
| **相關連結** | 動態 | **必須填入原始真實 URL 網址（例如：`https://tuoitre.vn/...`），嚴禁填寫越文或中文說明文字**。 |

## 二、表格下方新聞內文排版規範

表格下方為正式越南文新聞內文，須遵守以下格式：
1. **段落架構**：嚴格依據五段式 SOP（導言、事件內容、影響、後續措施、歷史背景）。
2. **字型設定**：英文/越文字型設定為 **Times New Roman**，字級 **12 pt**。
3. **段落間距**：段前間距 **12 pt**（或 240 dxa），段後間距 **12 pt**（或 240 dxa），行距為 **1.15 倍**。
4. **文字色彩**：全文皆為標準黑色（`#000000`），不帶任何背景網底或底色。

## 三、產出目錄管理原則

1. **範本單一來源（SSOT）**：
   * 標準空白 Word 範本統一存放於 [`templates/新住民全球新聞網_上稿單範本.docx`](../templates/新住民全球新聞網_上稿單範本.docx)。
   * 每日產出目錄（如 `20260906/DOC範本/`）**嚴禁重複放置空白範本**，亦不放冗餘說明檔。
2. **每日產出目錄職責**：
   * `YYYYMMDD/DOC範本/` **僅存放當日已填寫完成之正式交付 Word 文件**（如：`VN20260906_01_越南新身分法.docx`、`VN20260906_02_海外越語推廣日.docx`）。
