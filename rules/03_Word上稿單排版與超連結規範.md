上稿單首頁表格各欄位之文字、圖片與連結填寫，必須嚴格符合以下格式要求：

| 欄位位置 | 欄位名稱 | 排版與填寫技術標準 |
| :--- | :--- | :--- |
| **Row 1** | **中文標題** | 繁體中文，字級 12 pt（微軟正黑體），純黑文字（`#000000`），**嚴禁添加紫色網底、黃色螢光反白或任何特殊底色**。 |
| **Row 2** | **外文標題** | 越南文，字級 12 pt（Times New Roman），純黑文字（`#000000`），**嚴禁添加任何底色**。 |
| **Row 3~8** | **固定分類欄位** | 新聞專區、專欄專題、一指通、影音專區等維持範本既有核選結構，保持固定，不予刪改。 |
| **Row 9 (左)** | **主圖 (配圖嵌入)** | 嵌入預先經過智慧裁切為 **約 516 × 292 等比例規格** 之配圖，圖片寬度設定為 **約 2.14 英吋（5.42 cm）**，清除儲存格內任何多餘段落底色。 |
| **Row 9 (右)** | **主圖 (圖說)** | 字級 11 pt（Times New Roman），純黑文字，嚴格遵循格式：**`主圖說明(Ảnh envato/{圖片名稱})`**（不加最外層大括號 `{}`）。 |
| **Row 10~12** | **插圖1/2/標籤** | 維持範本固定結構（插圖 2 維持 `（圖／提供）`）。 |
| **Row 13** | **關鍵字** | 填入 4 個越南文核心主題關鍵字（以半形逗號及空格分隔），字級 11 pt（Times New Roman），純黑字體，無網底。 |
| **Row 14** | **相關連結** | **必須填入原始真實完整 URL 網址（如 `https://tuoitre.vn/...`）**，嚴禁填入越文或中文說明文字。 |

## 三、底層超連結同步與嚴格一致性審核機制

在 Word OpenXML（`.docx`）文檔架構中，超連結由「儲存格可見文字」與「底層 XML 關聯目標（`document.xml.rels` 中的 `rel._target`）」兩部分組成。為避免點擊跳轉至錯誤文章，建立以下技術審查規範：

1. **雙向同步更新**：
   * 程式自動填入「相關連結」時，除了更新儲存格 `<w:t>` 顯示文字外，**必須同時更新其底層超連結關聯目標（`doc.part.rels[rId]._target = target_url`）**。
2. **底層關係 Assert 一致性校驗**：
   * 自動生成模組必須在儲存文檔前執行斷言校驗：
     $$\text{Assert: } \text{doc.part.rels[rId].target\_ref} == \text{target\_url}$$
   * 確保底層關聯目標與顯示網址 100% 吻合，徹底杜絕範本舊連結（如已淘汰之菸草新聞網址）殘留。
3. **新聞內容來源一致性審核**：
   * 填入之 URL 網址必須與當日該篇新聞稿提取之原始報導出處完全相符，嚴禁張冠李戴。

## 四、表格下方新聞內文排版規範

表格下方之五段式越南文新聞內文，其段落與字體必須符合以下排版標準：

* **字型字級**：Times New Roman，字級 12 pt。
* **文字顏色**：標準純黑色（`#000000`），清除任何段落背景或文字底色。
* **段落間距**：段前間距 **12 pt**（`space_before = Pt(12)`）、段後間距 **12 pt**（`space_after = Pt(12)`）。
* **行距設定**：**1.15 倍行高**（`line_spacing = 1.15`）。
* **結構呈現**：依據標準五段式架構（導言、事件主體、影響、後續措施、背景脈絡）分段落獨立排版。
