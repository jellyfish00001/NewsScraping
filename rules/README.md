# 專案採編與上稿唯一權威規則體系 (Rules Index)

本目錄為「新住民全球新聞網」政府標案之**唯一權威規範專區**。  
為落實單一權威來源原則（Single Source of Truth, SSOT），本目錄依照專業面向拆分為 4 份互不重疊、各司其職之獨立規範檔案，**嚴禁任何規則在不同檔案中多次提及**。

---

## 規則檔案架構與職責導覽

```text
rules/
├── README.md                          # [本索引] 規則體系架構導覽
├── 00_規則體系總綱與目錄管理規範.md      # 體系原則、SSOT 職責分工地圖、YYYYMMDD 與目錄清整防呆
├── 01_新聞選題與審查紅線規範.md          # 標案中立性、三大一票否決紅線、四大正向領域、來源分級
├── 02_新聞改寫與11步SOP規範.md          # 十大核心編譯原則、11 步 SOP、五段式字數規格、圖說標準格式
└── 03_Word上稿單排版與超連結規範.md     # 上稿單範本依據、欄位填寫、底層超連結同步審核、內文排版樣式
```

### 1. 體系與目錄管理
* 📖 **[`00_規則體系總綱與目錄管理規範.md`](./00_規則體系總綱與目錄管理規範.md)**
  * 定義全專案單一權威來源（SSOT）與零重複記載準則。
  * 規範 `YYYYMMDD/` 產出目錄結構（配圖、`AI文字內容/`、`DOC範本/`）。
  * 規範 `templates/` 與 `DOC範本/` 之清整防呆準則。

### 2. 選題與審查門檻
* 📖 **[`01_新聞選題與審查紅線規範.md`](./01_新聞選題與審查紅線規範.md)**
  * 政府標案行政中立原則。
  * 三大一票否決紅線：嚴禁政治議題、嚴禁涉中國/港澳/南海主權摩擦、嚴禁腥羶色/血腥暴力/八卦娛樂。
  * 四大正向聚焦領域：新住民權益福祉、居留與民事法規、政府便民措施、文化文教共融。
  * 來源風險分級（A/B/C 級）與事前 6 項快速檢核門檻。

### 3. 編譯改寫與 SOP
* 📖 **[`02_新聞改寫與11步SOP規範.md`](./02_新聞改寫與11步SOP規範.md)**
  * 十大核心編譯原則（不直譯、不抄標題、保留客觀事實要素、道地 *Tiếng Việt tự nhiên* 等）。
  * 完整 11-Step 標準作業流程（SOP）：分類、來源機構與 URL、不可變客觀事實、雙語標題與五段式內文篇幅規格、雙語關鍵字、4 選 1 功能 Tag、圖說唯一標準格式 `主圖說明(Ảnh envato/{圖片名稱})`、四維度風險評級、新住民適配性五星評估。

### 4. 上稿單排版與技術規範
* 📖 **[`03_Word上稿單排版與超連結規範.md`](./03_Word上稿單排版與超連結規範.md)**
  * 單一空白範本依據（`templates/新住民全球新聞網_上稿單範本.docx`）與放置說明（`templates/README.md`）。
  * 上稿單表格 14 欄位詳細填寫標準（中文/外文標題純黑無底色、516*292 配圖嵌入寬度、圖說、關鍵字、原始真實 URL）。
  * 底層超連結同步與 Assert 一致性校驗機制（消除舊連結殘留）。
  * 表格下方五段式內文排版樣式（Times New Roman 12pt、段前段後 12pt、行距 1.15 倍、純黑無網底）。
