# 新住民全球新聞網 越南新聞採集與編譯專案 (NewsScraping)

本專案為政府補助標案之越南新聞採集、審核篩選與編譯改寫專案。  
依據官方標案驗收標準及「新住民全球新聞網」專業編輯 SOP，建立完整之規範手冊與發稿範本。

---

## 專案架構與文件導覽

### 🤖 代理人維護核心
* 📜 **[AGENT.md](./AGENT.md)**：AI Agent 與專案維護運作規範，記錄角色定位、三大紅線、11 步 SOP、目錄索引與強制連帶更新機制。

### 📁 rules/ 規則手冊專區
* 📕 **[01_政府標案與新聞篩選紅線規範.md](./rules/01_政府標案與新聞篩選紅線規範.md)**
  * **三大一票否決紅線**：零政治敏感、零涉中議題、零腥羶色暴力煽情。
  * **四大正向聚焦領域**：新住民權益、法規保障、政府政策、文化教育與在地生活。
  * **來源等級與事前自我檢核表 (Pre-Curation Checklist)**。
* 📘 **[02_新住民全球新聞網_編譯SOP規範.md](./rules/02_新住民全球新聞網_編譯SOP規範.md)**
  * **十大核心原則**：不直譯、不沿用原標題架構、道地越南語（Tiếng Việt tự nhiên）、客觀中立、事實不可變更。
  * **完整 11-Step SOP 流程**：分類判斷、來源分級、事實提取、五段式改寫、雙語關鍵字、功能 Tag 判定、圖說標準、四維度風險評級與適配性星級評估。

### 📁 templates/ 發稿範本與指令專區
* 📝 **[新聞編譯標準發稿範本.md](./templates/新聞編譯標準發稿範本.md)**
  * 標準上稿空白表單結構（STEP 1 ～ STEP 11）。
  * 完整實務範例（越南勞動證照線上換發新規示範）。
* 🤖 **[AI_改寫指令Prompt範本.md](./templates/AI_改寫指令Prompt範本.md)**
  * 提供給 ChatGPT / Claude / Gemini 等大模型使用的一鍵改寫 Prompt，確保產出格式 100% 合規。
