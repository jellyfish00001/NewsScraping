# 越南新聞採集與編譯專案 (NewsScraping)

本專案為政府補助標案之越南新聞採集、篩選與改寫專案，旨在彙整對在台越南新住民具實用價值之正向資訊。

---

## 專案規範與文件目錄

* 📋 **[新聞篩選與採集規範.md](./新聞篩選與採集規範.md)**
  * **三大嚴格過濾紅線**：嚴禁政治內容、嚴禁涉中議題、嚴禁腥羶色與煽情犯罪。
  * **三大核心聚焦主題**：新住民權益保障、法律法規與司法保障、政府政策與便民措施。
  * **採集品質與來源審核檢核表 (Checklist)**。

* 📝 **[新聞採編與撰寫模板.md](./新聞採編與撰寫模板.md)**
  * **第一部分**：新聞原始資料與來源記錄表（供履約驗收與查驗佐證）。
  * **第二部分**：新聞改寫與發稿標準模板（含 30 秒摘要、背景、核心內容、新住民權益專欄與諮詢管道）。
  * **第三部分**：完整實務範例示範。
